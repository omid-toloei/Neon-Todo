# 📝Neon-Todo

A minimal dark-themed to-do list app with neon green accents.

Built with vanilla HTML, CSS & JavaScript — no frameworks, no dependencies.

## 🎯Features

- Add/delete tasks
- Persists data with localStorage
- Live unfinished task counter
- Responsive
- Persian/Arabic font support (IranCell)

## Run

Just open `index.html` in your browser.
